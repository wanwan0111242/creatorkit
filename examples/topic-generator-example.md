# Example: topic-generator

Realistic demo of what the skill produces. Input is the user's message; output is what the skill returns before the user picks a direction.

## Input

> I run a small newsletter for indie developers. Give me topic ideas about "selling digital products".

## Output (abridged)

```
1. "What Actually Sells: 3 Digital Products Real Indie Devs Bought This Year"
   - Angle: reverse-engineer purchase decisions from public revenue screenshots, not generic advice.
   - Outline: 3 product types (template, course, community) → what buyers said sold them → pricing patterns
   - Workload: ⭐⭐ (needs 5–8 real examples)
   - Pros: concrete and data-driven, stands out in a crowded space
   - Cons: requires collecting verifiable examples, slower to produce

2. "My First $100 from a $3 Product (and What It Taught Me)"
   - Angle: honest first-sale post with a real number and real mistakes.
   - Outline: product idea → build (2 evenings) → launch → first 10 buyers → lessons
   - Workload: ⭐ (personal story, fastest to write)
   - Pros: authentic, relatable, low research needed
   - Cons: only useful if you have (or will run) the real experiment

3. "Pay-What-You-Want Pricing: A Field Guide for Small Makers"
   - Angle: decision framework (floor price, suggested price, funnel placement) with 3 case studies.
   - Outline: when PWYW works → setting the floor → case studies → anti-patterns
   - Workload: ⭐⭐⭐ (needs case-study research)
   - Pros: high perceived value for makers; evergreen
   - Cons: heavier research; risk of generic if case studies are thin

4. "The $9 Template That Took 4 Hours to Build"
   - Angle: case study breakdown of a real low-effort digital product.
   - Outline: why a template → build log → distribution → conversion numbers
   - Workload: ⭐⭐ (real build + screenshots)
   - Pros: step-by-step replicable; great for beginners
   - Cons: requires doing (or having done) the build; income claim must be honest
```

## Notes

- The skill never writes any of these articles — it waits for the user to pick.
- Every option lists a genuine con; no option is uniformly praised.
- Options span different content types (analysis, personal story, guide, case study).
